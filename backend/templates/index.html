Security tools

These tools provide basic educational checks. They do not replace professional security testing, antivirus software or threat-intelligence services.

Password strength analyzer

Your password is checked in memory and is never saved or logged.

Phishing URL pattern check

Checks visible URL patterns only; it does not query reputation databases.

Local network connectivity check

Checks only TCP port 80 on localhost or a private/local network address. Only test systems you own or are authorized to assess.

File SHA-256 fingerprint

Calculates a fingerprint; it does not detect malware. File size limit: 20 MB.
